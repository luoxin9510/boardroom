# 哥布林山脉 Goblin Mountain（单人）

> 状态：v1.0 定稿（2026-11-16）。平台约定见 [平台 PRD](../prd.md)。
> 原作：Roman Flückiger，9 张卡 PnP 比赛作品，v1.2.2（2018），版权所有。
> **卡图、卡面数据、规则原文只放 vault**（`iCloud~md~obsidian/Documents/goblin-mountain/`）；公开仓库只有规则的代码实现和原创测试卡。

## 1. 范围

- **只做单人模式**：裂谷 Chasm（普通）和地下墓穴 Catacombs（困难）两种难度。
- 完整执行规则：合法目的地高亮、地点效果、掉队惩罚、潜行骰、哥布林王、计分和评价全部自动结算；另有手动调整。
- 双人模式、冒险者选秀变体放到「之后」。

规则要点和裁定在 vault 的 `规则/规则要点.md`、`规则/裁定.md`。

## 2. 裁定（作者 2026-11-16 采纳）

1. **掉队惩罚**：从隧道上拿起一颗骰子时，它身后的己方骰子全部 −1，**包括还没上路的**。移动一颗没上路的骰子时，其他没上路的不扣。
2. **单人下的两格地点**：只能放 1 颗，执行 ①。
3. **哥布林王**：前进途中进入第一个有你骰子的地点就停下，那颗骰子 −1，剩下每一步再 −1；骰子被抓后还有剩余步数，就继续前进。同一地点有多颗骰子时，由玩家选扣哪颗（待选）。王所在的地点上只要还有骰子（上回合挨打没死，或玩家把骰子移了过来），他之后的每一步都变成 −1，不会越过活着的骰子。哥布林王从巢穴第 6 格走到第 1 格；第 1 格就是冒险者的起点（骰子开局放在巢穴最后一格），再下一步进入隧道第一个地点，这时巢穴翻成村庄。
4. **没有合法移动**：这一回合跳过，不掷潜行骰，哥布林王照常前进 1 步。
5. （双人用，现在用不到）一方结束后另一方继续走完。
6. **地点条件按移动前的点数判断**：经过「经过 −1」的地点后点数变了，也照样落在选好的地点。

## 3. 内容包格式（vault）

```
goblin-mountain/
  boardroom.json            { "game": "goblin-mountain" }
  卡牌/
    图/                     牌面图（已切好、转正）
    A.md … M.md             普通隧道卡，每一面一篇
    裂谷.md  墓穴.md        单人特殊隧道
    村庄.md  巢穴.md        村庄、哥布林巢穴
  规则/  对局/  对局/存档/
```

每篇卡面笔记：

```markdown
---
type: tunnel          # tunnel | special | village | warrens
card: 1               # 第几张实体卡
side: A
back: G
image: 图/隧道卡1-A.jpg
---
| 位置 | English | 中文 | 条件 | 费用 | 奖励 | 奖励② | 可重复 |
|---|---|---|---|---|---|---|---|
| 1 | Locked Room | 上锁的门 | 黑=2 | | 名望+1 村民+2 | | |
| 2 | Hideout | 藏身处 | | | 设为5 | 付宝藏1 设为4 | |
| 3 | Icy Depths | 冰窟 | 蓝≤2 | | 名望+2 命运+1 | | |
| 4 | Goldmine | 金矿 | 黄 | | 宝藏+X | 宝藏+X/2 | |
```

（上表只是示例，真实数值以录入为准。）

- **条件**：颜色是黄、橙、蓝、黑，点数写成 `≥4`、`≤3`、`=2`；空着表示任意颜色、任意点数。
- **效果词汇**（中英都认）：`名望+N` `宝藏+N` `村民+N` `命运+N`、`宝藏+X`（X 为骰子点数）、`宝藏+X/2`（向上取整）、`设为N`、`骰子+N`（最多到 6）、`翻面`、`经过-1`（被经过时 −1，地点上有骰子就抵消）、`不动+1`（停着不动每回合 +1）、`二选一(A | B)`。
- **费用**：`付宝藏N`，写在「费用」列或奖励里。
- **可重复**：打 ✓ 表示付得起就能重复执行（藏匿点、许愿井）。
- 单人特殊卡用 frontmatter 的 `insert: 3/3` 或 `insert: 2/4` 写插入位置；巢穴卡写 6 个格子。
- 村庄的前 4 名奖励写在 `村庄.md` 的表里。
- 每张卡分成 4 个地点竖条，默认把卡图等分成 4 份；不准的话在 frontmatter 里写 `strips: [x1, x2, x3, x4, x5]` 覆盖。有卡图时隧道里每个地点显示它那一段卡图（保持原比例），下面一行是当前语言的地点名；没卡图时显示文字卡片。
- 笔记正文里可以随意写别的（比如 `![[卡图]]`），解析器只读表格。
- 解析器报错要指出文件、行、列，并说明应该怎么写。

## 4. 界面（竖屏，440×956 为主）

```
┌──────────────────────────────┐
│ ✕   潜行 ⚀⚂⚀⚄   👑 距你 3 格   中/EN ⋯ │  顶栏：退出沉浸、潜行骰、哥布林王、语言、菜单（撤销、手动调整、重开、规则）
├──────────────────────────────┤
│  👑                             │
│ ┌────┐┌────┐┌────┐┌──┐        │  隧道：横向滑动，每个地点一张竖条卡图，
│ │卡图││卡图││卡图││  │ →      │  叠加中英名、条件徽标、效果说明；
│ │    ││    ││    ││  │        │  哥布林王在上方，你的骰子在下方
│ └────┘└────┘└────┘└──┘        │
│   🟨5        🟦2                │
├──────────────────────────────┤
│ 名望 12  宝藏 6/8  村民 2  命运 1 │  底部面板：资源、4 颗骰子（大按钮）、
│ [🟨3] [🟧3] [🟦3] [⬛3]  [命运]  │  命运按钮；点骰子 → 合法目的地发亮并自动滚过去
└──────────────────────────────┘
```

一回合的流程：点骰子 → 合法地点发亮 → 点地点放下 → 弹出地点动作（执行 / 跳过，可重复的用加减器）→ 掷潜行骰 → 哥布林王走、扣点 → 下一回合。所有操作都能撤销（地点动作面板里也有撤销）。M0 用顶部的短提示播报潜行骰、哥布林王和掉点；骰子动画和哥布林王逐步行走留到 M3。

结束页：计分明细、评价（5 档，中英）、「写进笔记」、「再来一局」。

## 5. 里程碑

### M0：平台骨架 + 引擎（原创测试卡）

- monorepo、CI、`core`（种子随机、会话、撤销、存档、待选、i18n 校验）。
- `games/goblin-mountain`：完整的单人规则引擎；内容包解析器；`fixtures/goblin-mountain` 用原创测试卡，格式和 vault 完全一样。
- 可用但不打磨的手机界面：隧道、骰子、底部面板、命运、地点动作、哥布林王、撤销、结束页、中英切换。
- `host-obsidian`：视图、沉浸、手势拦截、屏幕常亮、读 vault 内容、存档和对局记录写进 vault、继续上一局。
- `host-web` 跑同一套界面；Playwright 在 440×956 视口下跑完一整局。
- 规则测试：规则书里的例子、每条裁定一个用例、随机对局 1000 局（永不抛错、不变量成立：宝藏 ≤ 8、点数在 0–6、骰子不会后退）。
- **验收**：在作者手机上的测试 vault（`boardroom-测试`，装原创测试卡）里，从开局玩到结束页，中途撤销、切换语言、退出后继续上一局。

### M1：真实卡牌（2026-11-16 作者定：先做这一步）

- 把 12 面普通隧道、2 张特殊隧道、村庄、巢穴录进 vault（agent 对照卡图录入，作者核对）。
- 隧道里显示每个地点那一段卡图（保持比例），下面一行当前语言的地点名；点地点看完整说明。
- 手机上游戏铺满全屏、自己处理安全区（修 M0 里顶部多出的一块空白）；起点只显示一个 ♛。
- 开发宿主可以读真实 vault 预览（`BOARDROOM_VAULT=… npm run dev`）。
- **验收**：作者在手机上的 `goblin-mountain` vault 里用真卡玩，核对卡面数据。

### M2：规则页 + 新手教程（2026-11-16 作者定）

- **规则页**：⋯ 菜单「规则」打开全屏页，章节可折叠（目标、回合流程、移动与掉队、地点、命运、哥布林王、村庄、计分、裁定）；地点说明和顶部提示里的关键词（如「掉队」「潜行骰」）点一下跳到对应章节。
- 规则内容放在 vault：英文原文（从规则书 PDF 整理，带图例）和完整中文翻译各一篇，末尾附 [[裁定]]；规则页跟随界面语言。商业规则只在作者的 vault 里，公开仓库只有渲染代码和占位规则。
- **新手教程**：互动引导局，约 10 步（选骰子、发亮地点、掉队惩罚、地点动作、潜行骰、哥布林王、命运、村庄与计分），每步高亮要点的地方，可跳过；第一次打开时问一次，菜单里能重看。教程用代码里固定的原创对局（规则一样、卡是编的），不依赖 vault 内容，e2e 可测。
