# 铁誓 Ironsworn（单人）

> 状态：规格 v1.0（2026-11-16，作者拷问两轮后定稿；独立审核后补了存档、后果词汇、掷骰数值条）。平台约定见 [平台 PRD](../prd.md)。
> 原作：Shawn Tomkin，Ironsworn（2018）。作者手上这版规则书和 Delve 的版权页写的是 **CC BY-NC-SA 4.0**（2026-11-16 核对过 PDF 第 3 页）。中文译本和角色卡表格是第三方作品，更只能放 vault。
> 和哥布林山脉一样：**规则原文、中文译本、动作/资产/先知表的全文只放 vault**（`iCloud~md~obsidian/Documents/ironsworn/`），公开仓库只有引擎、界面和原创测试内容。作者的资料：英文核心规则书、Delve、中文译本（docx）、中文角色卡表格 v1.3（xlsx），以及几本第三方补充（Arcanum、Quest Fronts、The Selkie Envoy、100 Ironsworn Waypoints、The Unspoken Vow、模型战斗规则）。

## 1. 范围

- **单人、一个角色**；可以有多个战役存档（书架里一个游戏下面多个战役）。
- **折中裁判**（作者决定 Q1=C）：引擎负责掷骰和判定（强成功／弱成功／失手、两颗挑战骰对子＝「极端结果或转折」，强成功也可能出现麻烦的转折）、气势（含烧气势、负气势抵消行动骰）、生命／精神／补给、苦痛、进度条和进度掷骰、经验。每个动作在某个结果下显示规则原文和**可选后果按钮**（如「+1 气势」「+1 补给」「标记进度」），点了就生效；选哪个、怎么解读由玩家决定。引擎不替玩家做叙事选择，也不强制「这一步只能用哪个动作」。
- **资产**：完整显示、可勾选升级（花经验）。资产加值**不自动套用**：掷骰面板里有「+加值」，旁边列出角色资产里提到这个动作的能力，玩家自己选。
- **骰子**：默认 App 掷；可以改成手动输入实体骰：d6、两颗 d10，查表和问先知的 d100（或两颗 d10 当十位和个位）。
- **先知**：核心规则书的全部 Oracle 表，加上作者 xlsx 里额外的剧情／人物／地点／简易地下城表，每张标来源。「问先知」按可能性：几乎肯定 90、很可能 75、五五开 50、不太可能 25、希望渺茫 10；d100 掷出对子（11、22…100）是意外转折。
- **日志**：每个战役一份。玩家写叙事，掷骰、先知、进度变化自动插入（例：「直面危险 +锋锐：5+2=7 对 3、8 → 弱成功」）。随时导出成 Obsidian Markdown（分享面板或下载）。
- **不做**（第一版）：Delve、Arcanum、地点表、冒险模组、模型战斗、多人、AI 叙事。按里程碑以后再加。完全离线。

## 2. 引擎规则（核心规则书，作者可在 vault 加裁定覆盖）

- **属性**：锋锐 Edge、心灵 Heart、钢铁 Iron、暗影 Shadow、机智 Wits，开局分配 3/2/2/1/1。（译名以作者确认的对照表为准，见 §4。）有的动作用数值条掷骰（承受伤害 +生命或+钢铁取高、承受压力 +精神或+心灵取高、扎营 +补给、给自己治疗 +钢铁或+机智取低），见 §3 的 `stats` 和 `pick`。
- **行动掷骰**：行动分 = d6 + 属性 + 加值，**最大 10**；对两颗 d10 比较：都大于 → 强成功；只大于一颗 → 弱成功；都不大于 → 失手。相等不算大于。两颗挑战骰点数相同 → 极端结果或转折（由玩家解读）。
- **气势**：开局 +2；范围 −6 到 +10；最大值 = 10 − 苦痛数；重置值 = 2（1 个苦痛为 1，2 个以上为 0）。**烧气势**：掷完后、选后果之前，气势取消**所有**比它小的挑战骰，被取消的算作已超过，然后气势回到重置值；气势 ≤ 0 不能烧，只有烧了能改善结果时才提示；进度掷骰不能烧。**负气势**：行动骰点数等于负气势的绝对值时，行动骰算 0。气势已在 −6 时再扣：按原文提示做「遭遇挫折」（Face a Setback），剩下的换成扣生命／精神／补给，或倒退一条进度条。
- **资源**：生命、精神、补给 0–5，开局 5。降到 0 时界面提示对应的动作（直面死亡、直面绝望……），不自动结算。生命或精神已是 0 时再受伤害／压力，剩下的转成扣气势（承受伤害／压力原文）。补给降到 0 时提示标记「无准备」。
- **苦痛**：状态（受伤、动摇、无准备、负重）、灾祸（残疾、腐化）、负担（诅咒、折磨），可手动勾选，影响气势上限和重置值。受伤时不能加生命、动摇时不能加精神、无准备时不能加补给（规则书「苦痛」一节），引擎执行 `health+` / `spirit+` / `supply+` 时检查并提示，玩家可以先清掉苦痛。
- **进度条**：10 格，每格 4 划。等级每次推进：麻烦 3 格、危险 2 格、艰难 1 格、极端 2 划、史诗 1 划。**进度掷骰**：已满的格数对两颗 d10，判定同上，不掷 d6、不能烧气势。誓言、旅程、战斗（敌人）、纽带都是进度条；纽带只有一条，每建立一条纽带推进 1 划。
- **经验**：完成誓言强成功按等级得经验：麻烦 1、危险 2、艰难 3、极端 4、史诗 5；弱成功少 1（麻烦 0 … 史诗 4）。新资产 3 点、升级 2 点。
- **主动权**：角色有「主动权」状态（加入战斗、猛攻、交锋等会得到或失去）；只在战斗中显示。
- **撤销**：所有操作都能逐步撤销（同哥布林山脉的会话日志），撤销连同它产生的自动日志一起退；日志里的手写文字单独编辑，不进撤销链。
- **存档**（和哥布林山脉不同，战役要玩几个月）：存档**不绑内容哈希**。存档里是一份状态快照 + 之后的动作列表；动作、资产、先知表都按 `id` 引用。存档另外保存当前状态和整份自动日志（日志不放在状态里，避免每一步复制、存档变大）。读档从快照开始重放，内容包更新（改译名、修错字、加表）后照样能继续；重放时按新内容取名字，所以改过的译名会出现在老战役里。重放失败（内容删掉了某个 `id`），或者重放出来的数值和存档不一样（内容改了规则或表），就直接用存档里的当前状态继续，只丢撤销记录，并提示一下；比较时不看名字，只看数值、进度条和随机数状态。快照每 50 个动作更新一次，同时保留上一个快照，所以撤销至少能退 50 步、可以跨过最近一次快照。快照里包括随机数生成器的当前状态，撤销和读档都不会改变随机结果。这要改 core 的会话和 host 的存档（PRD §4.2，M0 做 core，M1 做 host）。

## 3. 内容包格式（vault）

```
ironsworn/
  boardroom.json            { "game": "ironsworn" }
  动作/                     每个动作一篇
  资产/                     每张资产卡一篇
  先知/                     每张表一篇
  真相/                     世界真相（建角第一步）
  规则/                     Rules.md 英文原文、规则.md 中文译本、术语对照.md
  战役/                     导出的日志（玩家把 App 导出的 Markdown 放进来；App 写不了 vault）
```

**动作**（`动作/直面危险.md`）：

```markdown
---
type: move
id: face-danger
category: adventure        # adventure | relationship | combat | suffer | quest | fate
zh: 直面危险
en: Face Danger
roll: action               # action | progress | none
stats: [edge, heart, iron, shadow, wits]   # 可掷的值：五个属性和 health / spirit / supply
# pick: max                # 可选：max＝取高、min＝取低（承受伤害、治疗自己）；不写＝玩家选
# progress 动作写 roll: progress 和 track: vow|journey|combat|bonds
---
## 触发
当你试图进行危险行为……（中文全文）

## Trigger
When you attempt something risky……（英文全文）

| 结果 | 中文 | English | 后果 |
|---|---|---|---|
| strong | （原文全文） | (original text) | momentum+1 |
| weak | （原文全文） | (original text) | 二选一(momentum-1 \| health-1 \| spirit-1 \| supply-1) |
| miss | （原文全文） | (original text) | move:pay-the-price |

（示例只演示格式，结果文字和后果以 vault 里整理的原文为准。）

结果列除了 `strong` `weak` `miss`，还可以有 `before`（掷骰之前先生效，如承受伤害先扣「敌人等级」的生命：`health-?`）和 `any`（不掷骰的动作，如付出代价：`oracle:pay-the-price`）。
```

- **后果词汇**：
  - 数值：`momentum±N` `health±N` `spirit±N` `supply±N`；`health-?` 这类问号＝让玩家输入数量（承受伤害等于敌人等级、压力看叙事）；`experience+N`；`initiative+` / `initiative-`（得到／失去主动权）；`mark:<苦痛id>` / `clear:<苦痛id>`。
  - 进度：`progress+1`（按该进度条等级推进一次）、`progress×harm`（造成伤害：按等级推进「伤害值」次，伤害默认 1，面板上有加减器，资产或武器可以 +1）、`progress+N格`、`bond+1`（纽带推进 1 划）、`harm+N`（把伤害加减器 +N，资产、武器用）；有多条可选进度条时（多个敌人、多个誓言）面板让玩家选哪条。
  - 跳转：`move:<id>`（提示接着做哪个动作）、`oracle:<id>`（掷这张表，付出代价、直面死亡等）。
  - 经验按等级：`experience+rank`（完成誓言强成功）、`experience+rank-1`（弱成功），等级取所选进度条。
  - 组合：`A & B`（同时生效，如 `progress+1 & supply-1`）、`二选一(A | B | …)`、`选N(A | B | …)`（选 N 项，如扎营、旅居「选两项」）、`可多选(A | B)`；空着＝只显示文字。
- **资产**（`资产/猎犬.md`）：frontmatter `type: asset`、`id`、`category: companion|path|combat|ritual`、`zh`、`en`、可选 `health: 4`（伙伴生命条，伙伴受伤走「伙伴承受伤害」动作）、可选 `field: 名字`（伙伴名等要玩家填的栏）；正文一张表：`| 序号 | 中文 | English | 默认 | 后果 |`，三条能力，`默认` 打 ✓ 的是起始就有的；`后果` 可选，写了的能力在相关动作的面板里多一个按钮（如 `harm+1`、`momentum+1`），只是方便，仍由玩家决定点不点。
- **先知**（`先知/行动.md`）：frontmatter `type: oracle`、`id`、`group`（核心／地点／人物／剧情／地下城……）、`zh`、`en`、`dice: d100`、`source`；正文一张表 `| 范围 | 中文 | English |`，范围写 `1-2`、`3`、`99-100`。
- **真相**（`真相/旧世界.md`）：frontmatter `type: truth`、`id`、`zh`、`en`；表 `| 范围 | 中文 | English | 任务种子 |`。
- 规则页沿用哥布林山脉的格式（`type: rules`、`lang`、`<!-- topic: id -->`）。动作卡本身带原文全文，规则页链接用于章节级概念，必需的 topic：`action-roll` `momentum` `progress` `debilities` `vows` `combat` `journey` `oracles` `experience`。
- 打包：`npm run pack` 打 `boardroom.json` 里 `folders` 列出的文件夹（铁誓：`{"game": "ironsworn", "folders": ["动作", "资产", "先知", "真相", "规则"]}`；不写时是哥布林山脉的 `卡牌`、`规则`），永远不打 `战役/`、`对局/`。
- 解析器报错指出文件、行、列和正确写法。中文、英文缺一个时界面回退到另一种语言。

## 4. 术语

- 英文用规则书原文术语。

## 5. 界面（竖屏，440×956 为主）

- **顶部常驻**：角色名、气势（含上限／重置值）、生命／精神／补给三条，点一下就能 ±1。
- **底部 5 个标签**：
  - **角色**：属性、资源、苦痛、纽带进度、经验、资产卡（能力勾选、伙伴生命）。
  - **动作**：按分类列出全部动作；点开显示触发条件和三种结果，「掷骰」→ 选属性、加值（旁边列出相关资产能力）、可选手动输入骰点 → 显示判定、意外转折、可否烧气势 → 该结果的后果按钮。
  - **誓言**：全部进度条（誓言、旅程、战斗、纽带），新建（名字、等级）、推进、进度掷骰、完成／放弃（经验）。
  - **先知**：问先知（可能性五档）、按分组的随机表，结果可以一键「记入日志」。
  - **日志**：时间线，手写条目＋自动条目；导出 Markdown。
- **建角向导**（第一次进战役）：世界真相 → 属性 → 3 张资产 → 纽带 → 背景誓言 → 开场事件誓言；每步可跳过、以后补。
- 规则页复用（英文原文／中文译本，跟界面语言），动作卡和提示里的关键词链接到对应章节。
- 手机界面硬要求同 PRD §4.5：不横向滚动、按钮够大、所有操作可撤销。

## 6. 里程碑

- e2e（WebKit 两种手机尺寸）：建战役、掷骰选后果、撤销、推进誓言并完成、问先知、导出日志、离线。
