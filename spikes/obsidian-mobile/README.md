# Obsidian mobile probe (throwaway)

Plain-JS plugin, no build. Opens a test view and checks, on a phone:
hiding Obsidian's header and nav bar, horizontal swipe vs. sidebar gestures,
screen wake lock, vault images, and writing a note. Answers and device info
are saved to `boardroom-spike-结果.md` in the vault.

Install: copy `manifest.json`, `main.js`, `styles.css` to
`<vault>/.obsidian/plugins/boardroom-spike/` and enable the plugin.
